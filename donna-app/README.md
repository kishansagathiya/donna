# donna-app

React Native iOS app for Donna.

## Setup

```bash
npm install
cd ios && pod install && cd ..
```

## Run (iOS)

```bash
npm start
# separate terminal:
npm run ios
```

Requires Xcode and the [React Native environment](https://reactnative.dev/docs/set-up-your-environment) for iOS.

Bundle ID: `com.donna.app`
